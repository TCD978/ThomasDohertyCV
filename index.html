Project case study

GitHub-powered project feed

I wanted the project list on this CV to reflect my latest public work without editing the page every time a repository changed.

How it works

The JavaScript fetches repositories from the GitHub API in order of their latest update, filters out forks, and displays each repository’s name, link, and description. It also shows a message if the request fails or no projects are available.

This keeps the repository list current when the page loads. The rest of my CV is maintained separately.
